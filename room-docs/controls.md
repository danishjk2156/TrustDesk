# Control tags

The drafter tags every factual claim with one of these. Generated by `python agents/evidence/search.py --list`; regenerate after editing the rules.

| Tag | What it checks |
| --- | --- |
| `db_encryption_at_rest` | Database storage encrypted with KMS |
| `kms_key_rotation` | KMS keys rotate automatically |
| `tls_in_transit` | Public endpoints use TLS 1.2+ |
| `https_redirect` | Plain HTTP redirects to HTTPS |
| `hsts` | HSTS header set |
| `db_tls_required` | Database requires TLS connections |
| `mfa_admin` | MFA required for admin actions |
| `mfa_all_users` | MFA enforced for every workforce user |
| `sso` | Workforce SSO |
| `password_length` | Minimum password length 14 |
| `password_reuse` | Password reuse prevented |
| `session_timeout` | Session timeout configured |
| `least_privilege` | Read-only role for auditors |
| `code_review_required` | Reviewed pull requests required on main |
| `audit_logging` | Multi-region audit trail |
| `log_integrity` | Audit log file validation |
| `log_retention` | Logs kept for a year |
| `network_flow_logs` | VPC flow logs |
| `db_backups` | Automated database backups |
| `multi_az` | Database runs multi-AZ |
| `deletion_protection` | Database deletion protection |
| `storage_versioning` | Object versioning on storage |
| `storage_public_access_blocked` | Public access blocked on storage |
| `waf` | Web application firewall on the public load balancer |
| `db_not_public` | Database not reachable from the internet |
| `db_network_restricted` | Database accepts only the app tier |
| `sast` | Static analysis in CI |
| `dependency_scanning` | Dependency updates and alerts |
| `secrets_scanning` | Secret scanning in CI |
| `container_scanning` | Container image scanning in CI |
| `vulnerability_disclosure` | Public vulnerability reporting channel |
| `storage_encryption_all_buckets` | Every S3 bucket has server-side encryption |
| `backup_restore_testing` | Backup restores are tested |
| `penetration_testing` | Independent penetration test |
| `dr_testing` | Disaster recovery plan is tested |
| `endpoint_protection` | Endpoint protection on staff devices |
| `data_deletion` | Customer data deleted on request or contract end |
| `background_checks` | Background checks for staff |
